# Description
This repo provides a description of spherical earth navigation using vector calculus. By using vector calculus the framework is more intuitive to the modern engineer that classical implementations using complex trigonometry. This framework solves more problems than the classical formulations and allows reconciling spherical navigation with many of the problems that are solved in autonomous systems.
